# 长安食游图鉴 - 长安·Hackers

> 先看懂一味，再走进一街。

西安在地美食探索与购买决策 Agent —— 以西安美食图鉴为入口，连接真实美食地点、门店菜单、价格、营业状态和消费方式，帮助游客和本地用户发现、理解、比较并规划一次可执行的西安美食探索。

**团队**：长安·Hackers

## 要解决的问题

游客在西安寻找美食时经常遇到：

- 不知道一道菜是什么、怎么吃；
- 攻略、短视频和点评内容碎片化；
- 不知道该去餐馆、街边摊、美食街还是巷子小店；
- 网红店、本地老店和临时摊位难以区分；
- 价格、评分和营业状态可能已经变化；
- 看到推荐后仍然无法决定去哪、何时去、怎样串联。

## 核心闭环

`	ext
浏览美食图鉴
→ 了解历史、食材与吃法
→ 查看真实美食地点（天地图标注）
→ 选择堂食、外带、街边购买或路线串联
→ 生成美食探索方案
→ 查看价格、营业状态和数据来源
→ 选择购买或前往
`

## 功能一览

| 模块 | 能力 |
|---|---|
| 当前图鉴 | 前八道菜自动轮播（3.6s/张），支持手动切换与详情弹窗 |
| 风味入长安 | 十四道菜品卡片（最多展示八道），按名称/分类/标签搜索，收集册页一行四个陈列全部菜品 |
| 去哪吃怎么吃 | 自然语言条件输入（地点/时长/预算/吃法），规则解析生成探索方案 |
| 循味成行 | 天地图真实地图标注店铺与路线站点，点击查看店铺详情，信息卡片直达菜品弹窗 |
| 沿街拾味 | 七家真实店铺（来自游陕西小程序截图），默认展示三家，列表页查看全部 |
| 来源核验 | 菜品历史附百科词条链接；店铺、评分均标注来源；缺失评分按规则补 90.0 并显式声明 |

## 主流程

1. 在图鉴首页浏览轮播的菜品图鉴。
2. 点击卡片查看历史、食材、步骤和消费方式。
3. 在「去哪吃，怎么吃」输入地点、时长、预算和吃法。
4. parseExploreQuery 解析条件，uildRoute 生成多地点路线。
5. 天地图标注切换为路线站点，点击站点卡片直达店铺与菜品详情。

## 数据真实性边界

- 菜品与店铺资料来自用户提供的「游陕西」小程序截图；历史内容参考百度百科公开词条。
- 截图未显示评分的菜品统一展示 90.0，仅用于补齐排序与视觉呈现，不代表平台真实评分。
- 营业状态标注「以门店实时状态为准」，不声称实时。
- 店铺坐标为演示坐标，正式版本需逐条核验。
- 项目不替代地图导航、支付、外卖或团购。

## 已知限制与后续方向
